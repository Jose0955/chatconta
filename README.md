# 📚 Material de docentes

Esta carpeta es para que los **docentes** suban material de sus clases, para
que Contín lo use como referencia extra al responder a los estudiantes.

## ¿Cómo subo un archivo?

1. Entra a esta carpeta en GitHub (`material_docentes/`).
2. Haz clic en **"Add file" → "Upload files"**.
3. Arrastra tu archivo y dale a **"Commit changes"**.
4. Reinicia la app en Streamlit Cloud (Manage app → Reboot) para que Contín
   lo lea. Si no reinicias, Contín seguirá usando el material anterior hasta
   el próximo reinicio automático.

## ¿Qué tipo de archivos puedo subir?

- `.txt` o `.md` — apuntes o notas de texto simple
- `.xlsx` o `.xls` — hojas de cálculo (ejemplos, ejercicios resueltos)
- `.pdf` — documentos, guías, folletos
- `.pptx` — diapositivas de tus clases

## Cosas importantes a saber

- Contín usa este material como **apoyo extra**, no como su única fuente —
  sigue respondiendo con su conocimiento general de contabilidad para todo
  lo que no esté cubierto aquí.
- Por ahora, Contín **no puede leer imágenes sueltas** (fotos, capturas de
  pantalla). Si tu diapositiva tiene texto, súbela como `.pptx` y sí lo leerá.
- Hay un límite de tamaño total (para no gastar de más en la IA), así que si
  subes documentos muy largos, Contín solo va a leer una parte de cada uno.
- No subas aquí información sensible ni datos personales de estudiantes.
